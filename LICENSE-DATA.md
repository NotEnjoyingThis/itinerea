# Data licences

The source code of Itinerea is licensed under the GPL-3.0-or-later (see [LICENSE](LICENSE)). Data is different: every data pack keeps the licence of its source.

**No data is distributed with the project yet.** This file will list each data pack, its sources and its licence as soon as it is published.

Licences expected for the planned data packs (PRD 12.1):

| Data | Source | Licence |
|---|---|---|
| Map tiles, places, points of interest | OpenStreetMap | ODbL 1.0 |
| Badge place lists, place popularity | Wikidata | CC0 1.0 |
| Travel guides and suggested itineraries | Wikivoyage | CC BY-SA |
| Car data | European Environment Agency (EU open data) | To be confirmed when the pack is built |
| Toll tables | Community contributions in this repository | To be decided before the first pack |
| Original graphics and icons | Itinerea contributors | CC BY-SA 4.0 |
