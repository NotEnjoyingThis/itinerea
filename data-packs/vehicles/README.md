**Status: not started. Planned for phase 2 (F2.5 Vehicle).** No script and no data yet.

| | |
|---|---|
| Content | Cars: make, model, version, energy source, declared consumption (WLTP), tank or battery size |
| Source | Open data of the European Environment Agency (PRD 5.2) |
| Licence | To be confirmed when the pack is built (see [LICENSE-DATA.md](../../LICENSE-DATA.md)) |

| Used by | `Vehicle` and `VehicleSnapshot` in `app/lib/core/models/` |

Values from this pack are always shown in the app with the label "declared value (WLTP)" (PRD F2.5).
