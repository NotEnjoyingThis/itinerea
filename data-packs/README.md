# Data packs

**Status: not started. Planned for phases 2–4.** This folder is a placeholder: it contains no scripts yet.

## Purpose

Scripts that turn open data into **static files** the app downloads and uses offline. The files are published with GitHub Releases: there is no server behind them. Each pack has its own version and can be updated without updating the app (PRD 4.6 and 4.9).

| Pack | Source | Used by | Phase |
|---|---|---|---|
| Vehicles (cars) | European Environment Agency open data | F2.5 Vehicle | 2 |
| Tolls and vignettes | Tables maintained by the community in this repository | F3.3 Tolls | 3 |
| Badge place lists | Wikidata, with manual review of the main cities | F4.1 Badges | 4 |
| Shop items | Defined in this repository | F4.2 Points and shop | 4 |

Data keeps the licence of its source: see [LICENSE-DATA.md](../LICENSE-DATA.md).
